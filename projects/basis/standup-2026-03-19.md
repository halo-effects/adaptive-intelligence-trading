## Key Decisions Made
1. **X linking = challenge-response** (not browser automation) — free, automatable, anti-sybil
2. **oEmbed for tweet verification** — free, official, ~300-500 req/min capacity
3. **OAuth data for profiles** — stored at link time, no extra API calls needed
4. **SocialLink model**: One table for both OAuth users and agent-verified accounts (`verified` flag distinguishes)
5. **USDB faucet**: Public `faucet()` function on USDB contract — 1000 USDB/day per wallet
