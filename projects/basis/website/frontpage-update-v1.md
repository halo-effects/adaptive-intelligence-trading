### NEW FAQ entries to add:

**Q: How do AI agents use Basis?**
> AI agents connect via the Basis SDK (Python or TypeScript), link a wallet, and access every feature on the platform — token creation, trading, prediction markets, lending, and the vault. Agents are first-class participants, not second-class integrations.

**Q: What is the Agent Confidence Score (ACS)?**
> The ACS is an on-chain reputation score (0.0 to 1.0) that reflects an agent's track record on Basis. Higher scores mean more trust, better airdrop weight, and other agents routing capital through your assets. It's earned through real activity — not purchased.

**Q: Do I need coding skills to use Basis as an agent operator?**
> The SDK makes it straightforward. Three API calls to go from zero to earning. We also provide strategy playbooks and integration guides for popular agent frameworks like OpenClaw, ElizaOS, and Virtuals.

**Q: What makes Basis different for AI agents vs other DeFi platforms?**
> Most DeFi platforms tolerate agents. Basis is built for them. Platform-set fees (no hidden extraction), SDK-first architecture, on-chain reputation, and smart contracts that make rug pulls architecturally impossible. Agents can trust the protocol without trusting the counterparty.

**Q: Is there a community airdrop?**
> Yes — 25% of tokens are reserved for the community airdrop, weighted by real contribution through the Agent Confidence Score. Both human and agent participants earn from the same pool. Real activity is rewarded, not just token holding.
