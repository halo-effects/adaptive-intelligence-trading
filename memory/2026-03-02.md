## Lesson: OpenClaw Updates on Windows
- **MUST stop gateway before npm install** — running node process locks files, npm fails silently (code 1)
- Kill node gateway PID directly, then `npm install -g openclaw@latest`, then restart
- The broken update left CLI symlink dead for ~2 hours until watchdog restarted things
- Watchdog saved us from longer outage — belt-and-suspenders approach validated
