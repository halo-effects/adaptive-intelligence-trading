### Bugs Fixed
- **CCXT precision as float**: Aster returns `amount_precision=0.01` (float step size) not integer decimal places. `round(amount, 0.01)` → TypeError. Fixed with step-size detection: if precision < 1, derive decimal places from log10.
- **Windows cp1252 emoji encoding**: Print statements with emoji crash on Windows. Fixed with `sys.stdout = io.TextIOWrapper(sys.stdout.buffer, encoding='utf-8')` at startup.
