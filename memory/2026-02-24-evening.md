## Root Cause Analysis — Brett's Diagnosis

### "It's all in the transitions. Sensitivity is too high."

1. **1h candles too noisy for macro decisions** — Conductor scores every hour, flips EXIT on minor dips
2. **Exit threshold of 50 is too low** — daily score hits 50 constantly
3. **Hardcoded transitions** — EXIT always went to MARKDOWN regardless of market state (partially fixed)
4. **No directional awareness** — transitions should check Conductor's current read, not follow fixed sequence
5. **CFGI ≥ 75 gate exists but bypassed by V12f** — V12f replaced it with ROC-3d < 4 (weaker filter)

### Brett's Key Insight: "The pattern is there but we are switching on and off too fast"
- His BTC daily chart showed textbook Wyckoff phases
- Wyckoff plays out over weeks/months — daily candles show it clearly
- 1h candles are just noise at this scale
- "Once we confirm markup, we stay in markup for a long time. Once we exit, we stay in markdown for a long time."

## Architecture Evolution — Brett's Direction

### Phase Model Simplification
- **Drop SPRING entirely** — "We probably don't need a spring"
- Once bottom is confirmed, EXIT back to whatever Conductor says (Markup, DCA, Markdown)
- Phases are long-duration: ride the phase until confirmed otherwise
- EXIT gracefully between phases

### Two-Timeframe Architecture
| Layer | Timeframe | Purpose |
|---|---|---|
| **Strategy** (Conductor) | Daily + Weekly confirmation | Phase detection, transitions, directional calls |
| **Execution** (DCA Engine) | 1h | Order placement, SO fills, TP exits, trailing stops |

- DCA engine stays on 1h — proven, effective for mean reversion
- Conductor moves to daily scoring with weekly confirmation
- 1h is for execution, not macro decisions
- "We originally built the DCA engine on 1hr candles because it was effective, however now that we are trying to capture bigger moves, going to longer timeframes may make sense"

### Phase Flow (Simplified)
```
Conductor reads market daily (weekly confirms):
  → MARKUP (bullish) → DCA buys aggressively, ride trend
  → DISTRIBUTION → EXIT longs gracefully
  → MARKDOWN (bearish) → ride shorts or sit in cash
  → ACCUMULATION → EXIT shorts gracefully, prepare for markup
  → Repeat
```

Every transition = Conductor directional check. No hardcoded sequences.
No SPRING phase. No fixed Wyckoff sequence. Just: "what does the market say NOW?"

## EXIT Philosophy
- **Accept small losses for bigger wins**: Brett: "It's OK if we take some losing trades as long we make up for them with bigger winners."
- Current engine obsesses over 100% win rate — holds losing positions for days trying to exit at breakeven
- If Conductor says markdown, just close longs and take the L. A -2% loss is nothing vs a 15-30% phase move.
- Positive expectancy > win rate. Few small losses exiting = cost of being correctly positioned for the next phase.
- This changes EXIT engine design: instead of slow trailing unwind, close faster when direction is confirmed.
