## Scanner Window Analysis (19:30 PDT)

Brett noticed the 30d scanner window missed 80% of TON's upside move ($1.40 → $2.80). Asked whether shorter windows would catch momentum earlier.

**Built**: Walk-forward analysis (`trading/spot/_scanner_window_backtest.py`) — tested 6 windows (7d, 10d, 14d, 21d, 24d, 30d) across 60 days × 45 coins.

**Findings**:
- 30d: highest avg DCA score (31.6), lowest churn (13.0%), 20% false positive rate
- 7d: caught TON 25 days earlier (Apr 12 vs May 7) but 32% FP rate, 23% churn
- 14d: stability sweet-spot (22% FP, 15% churn) but same timing as 30d for most coins
- All windows 10d+ converged to same promotion dates within 1-2 days

**Verdict**: 30d window correct. Late detection is a data availability issue, not window size.
