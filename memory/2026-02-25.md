### Engine Features (v13_phase_backtest_v8.py)
- **4 phases**: DCA → MARKUP → FLAT → MARKDOWN
- **Markup entry**: HH_HL + Fib_support + SMA200 overextension gate (<20%)
- **Markup exit (5 layers)**:
  1. Early warning: 1W StochRSI crosses below 97
  2. Primary: 2W StochRSI OB exit at 93
  3. Fallback: 1W OB85 when 2W never reached OB
  4. Failsafe: 1W K<50 after armed
  5. Ranging: ADX<20 sustained 21 days
- **Markup failure**: DD>25% + ADX>25 = bail to FLAT
- **FLAT routing (3 paths)**:
  - From top signal → check for MARKDOWN (ADX+Fib_break), max 42d eval
  - From ranging exit → wait for ADX<20 14d → DCA
  - From markdown → wait for ADX<20 14d → DCA
- **Markdown entry**: ADX>20 + Fib_break (SMA200 gate removed)
- **Markdown exit**: ADX<20 sustained 21 days (trend exhaustion)
- **Markdown failure**: Price rises >25% above short entry + ADX>25
- **Short tiers**: T1=60%, T2=20%, T3=10% (symmetric with markup)
- **DCA**: 8% BO, 2.5% SO deviation, 1.5x multiplier, 1.5% TP, max 8 layers
- **Min phase hold**: 3 days

## Key Lessons Learned
1. **Multiple files with similar names = disaster** — `v13_backtest_v8.py` and `v13_phase_backtest_v8.py` are completely different engines with the same class name
2. **Always verify backfill matches standalone backtest trade-for-trade** before calling it done
3. **Daily tick timing matters** — first-hour price ≠ daily close, off-by-one-day shifts cause signal misalignment
4. **DCA PnL ≠ Total PnL** — markup sells and short closes are where the real money is
5. **candles.db not in .gitignore = time bomb** — git operations can wipe runtime data
6. **GitHub Pages has a 10 builds/hour rate limit** — pushing every 2 min = 30 builds/hour = all builds fail
7. **Broken git submodules (no .gitmodules) cause instant GitHub Pages build failures** — duration=0s errors with no useful message
8. **Two git workflows pushing to same branch = file deletion chaos** — auto-backup deletes files it doesn't track, sync script re-adds them, cycle breaks Jekyll
9. **Always add `.nojekyll` to GitHub Pages repos serving static HTML** — Jekyll processing is unnecessary and can break builds
10. **Dashboard stat cards must read from trades.csv, not status.json** — V13 engine's status.json only tracks open positions (realized_pnl=0, win_rate=0). Historical stats come from trades.csv.
