### Key Technical Findings
- **GitBook paste via `text/plain`**: Reliable. Prose, headings, bold, lists all render correctly. Tables render as plain text (not formatted).
- **GitBook paste via `text/html`**: Renders tables in editor view but **does NOT persist**. GitBook saves the `text/plain` fallback. DO NOT USE for actual content.
- **Lesson learned**: Always set `text/plain` to full content even when providing `text/html`. Or just use `text/plain` only.
