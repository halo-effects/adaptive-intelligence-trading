### Git Stability Root Cause Fix
**Problem**: Two git processes fighting over the same remote repo:
- OpenClaw cron "Workspace Git Backup" (hourly): `git add -A` + push from workspace
- Windows task "AIT_DashboardSync" (every 10 min): separate temp clone, `git reset --soft origin/main`

When sync pushes to remote, backup cron's merge/rebase can silently drop local-only code changes. This is why source files kept getting deleted.

**Fix**: 
- Updated `.gitignore` to exclude all trading bot source files and runtime state
- Pushed to remote so both processes respect it
- `git rm --cached` on 3 tracked source files
- Source files now exist only on disk, never in git
