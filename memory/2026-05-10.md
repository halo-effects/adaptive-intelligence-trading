## Signal Data Architecture (for reference)
Two-tier system — signals don't need engine-level warmup:
- **Tier 1 (candles.db)**: 79 symbols with full daily history. Updated by data sync cron independently of active trading. `V13SignalPack` loads from here — all indicators computed from existing history.
- **Tier 2 (1h candles)**: Per-engine, ephemeral. Accumulated from exchange WebSocket. Warmup replay suppresses actions on old candles, only current candle executes.
- When scanner promotes a new coin, engine constructor loads signal pack from candles.db (history already there). Only needs to accumulate a few 1h candles for intraday DCA grid.
