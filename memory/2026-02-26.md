### Lessons Learned
- **Sentiment momentum (CFGI RSI) > absolute sentiment (CFGI threshold)** — relative measure adapts to different regimes
- **Coin-specific CFGI > market average** — individual coin sentiment diverges from market (BTC Jun 2024)
- **Python output buffering with PowerShell**: No `-u` flag on backfill script caused ~15 minutes of silent execution with no visible output. Always use `python -u` for long scripts.
- **DB schema varies between tables**: `candles` uses (symbol, timeframe, timestamp), `candles_daily` uses (symbol, date). Always check PRAGMA table_info first.
