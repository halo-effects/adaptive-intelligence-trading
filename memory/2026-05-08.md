# 2026-05-08 — Major Incident: Restart Cascade + DEX-as-Truth Fix

## Incident Summary
Data sync cron on May 6 committed a truncated `v14_capital_manager.py` to git. Bot ran in memory fine (masking the break) until manual restart. 113 spread-reject round trips during restart attempts, $5.75 lost, CSV corrupted, capital tracking destroyed.

## Timeline
- **Morning**: Bot restart fails (ImportError on capital_manager). Multiple restart attempts create spread-reject churn.
- **~8:00 AM**: Candle replay guard deployed (300s threshold) — stops churn but threshold too tight for 1h candles.
- **~12:00 PM**: Discovered replay guard was suppressing ALL candle actions (300s < 3600s candle age). Fixed to 4500s.
- **12:25 PM**: Bot restarts but reconciliation re-corrupts CSV with phantom trades (-$94.79 TON, -$22.65 PENDLE).
- **12:28-12:40 PM**: Multiple restart attempts — reconciliation + deposit detection create cascading phantom transactions. Capital bounces between $597, $385, $288.
- **12:50 PM**: Root cause identified: 5 systems fighting over capital (CLI, state.json, ledger, reconciliation, deposit detection).
- **1:00 PM**: DEX-as-truth startup implemented — exchange balance IS capital.
- **1:06 PM**: Auto deposit detection disabled (formula broken for DEX-as-truth).
- **1:13 PM**: Bot starts clean. Capital $385.06 matches DEX. No phantom transactions.
- **1:18 PM**: Data sync script fixed (Windows pathspec bug). Sync repo nuked for fresh clone.

## Root Causes
1. Data sync cron committed source file (`v14_capital_manager.py`) due to Windows pathspec negation bug
2. In-memory state masked the break for days
3. Reconciliation heuristics can't handle churn fills
4. Deposit detection formula assumes tracked_capital = seed (breaks when tracked = exchange balance)
5. No release process — code changes are local file edits, any git pull overwrites them

## Changes Made
- `run_v14_portfolio_live_aster.py`: DEX-as-truth startup, disabled reconciliation, disabled auto deposit detection, replay guard 4500s
- `sync_dashboard.ps1`: Explicit per-file unstage loop (replaces broken `:!docs/` pathspec)
- `capital_ledger.json`: Reset to clean seed=$300
- `state.json`: Reset capital to $385.09
- `trades.csv`: DEX-verified corrections (95 trades, $96.74 PnL)

## New Hard Rules (19-24)
- Pre-flight import test before every restart
- Never batch unrelated fixes
- Spec → approval → pre-flight → restart
- Data sync must never commit source files
- DEX is sole source of truth for capital
- In-memory state is not validation
