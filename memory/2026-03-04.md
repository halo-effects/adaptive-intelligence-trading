### Critical Lessons (Live Trading)
- **Engine state mutation before exchange confirmation is dangerous**: `engine.tick()` closes deals internally, THEN the runner tries to execute on exchange. If exchange rejects, engine already moved on. Fix: snapshot before tick, rollback on failure.
- **Sell execution failure must block trade recording**: The runner's `_execute_action` correctly checked return value for tracker, but the engine's internal state was already mutated by tick(). Two-phase commit pattern needed.
- **Fee/rounding drift is inevitable on spot exchanges**: Tracked qty will always drift slightly from exchange balance over time. Always sell `min(tracked, actual)`.
- **Position reconciliation is a must-have for live**: Need a periodic balance check that compares engine state vs exchange state and alerts on drift.
