## Lessons Learned

### Duplicate Bot Instance Risk
- Windows Scheduled Tasks + manual starts = duplicate processes
- No locking mechanism in run_v14_live_aster.py to prevent this
- Fix needed: Add PID file check at startup (`live/v14/bot.pid`), exit if already running

### OpenClaw Retry/Failover Behavior
- No exponential backoff on rate limits — retries at 2s, 4s, 8s then gives up
- Failover chain: Gemini → Claude Opus (most expensive!) — terrible default
- Need to configure failover to use Haiku or Sonnet, not Opus

### Cron Token Burn
- Every cron job spun up a full Claude Opus 4-6 agent turn
- Hourly git backup × Opus = ~400k tokens/day wasted on `git add && git commit`
- Rule: cron jobs should use the cheapest model that can do the job
