**Root causes:**
- `last_candle_ts` initialized at 0 on restart → replays ALL 200 hourly candles
- No impact analysis before starting changes
- Didn't verify all processes killed before editing files
- Panicked instead of making surgical fix

**What I should have done:**
1. Stop bot, verify ALL processes dead
2. Edit state.json (flip phase only)
3. Initialize `last_candle_ts` to current time to prevent historical catchup
4. Restart with --skip-backfill
5. Verify no retroactive trades
6. If retroactive trades appear, remove ONLY those specific trades
