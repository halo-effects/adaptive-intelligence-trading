# 2026-05-11 — Auto Deposit Detection + System Audit

## Auto Deposit/Withdrawal Detection
- Brett deposited $40 USDT into Aster live account
- System had no auto-detection (disabled 2026-05-08 due to broken formula)
- Built new detection: consecutive balance comparison approach
  - `expected = prev_balance + pnl_delta + funding_delta`
  - `drift = actual - expected`
  - Threshold: `max($5, 2% of capital)` = ~$8.46
  - Fires within 60s of DEX balance change
- Startup reconciliation: `dex_total - ledger_capital - csv_pnl` (stable values only)

## Critical Fix: Cascade Prevention
- First version used unrealized PnL in startup reconciliation
- Unrealized is volatile between restarts → false deposit/withdrawal triggers
- Each false trigger shifts baseline → cascades on subsequent restarts
- Fix: removed unrealized from formula entirely
- Verified: 3 consecutive restarts, delta=$0.00

## Capital Ledger Baseline
