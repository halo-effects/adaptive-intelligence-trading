### Incident

### Fixes Applied
1. **LIVE GUARD**: When `_tp_order_id` is set, engine TP sells are BLOCKED and engine state ROLLED BACK. Only non-TP sells (phase close, signal exit) can proceed.
2. **Fill price fix**: `execute_sell()` and `execute_buy()` never fall back to engine price. Fetches ticker if exchange doesn't return fill.
3. **PnL from actual fills**: Calculates from actual exchange proceeds, not engine's TP-price math. Engine capital corrected after sells.
